域名链接：[山西奶龙大学.cn](https://山西奶龙大学.cn)

### 信息提交方式

1. 在[仓库表单](github.com/SXU-Opensource-Association/ShanixNailoongUniversity/issues)中提交你的信息。

2. 拉取本仓库，直接在 `index.html` 里的 `clubsData` 中添加你的组织信息，后提交[推送请求](github.com/SXU-Opensource-Association/ShanixNailoongUniversity/pulls)。

### 信息提交内容

需包含下列信息：

0.  组织所属院校
1.  组织名称
2.  组织简介（不得多于 50 汉字或 100 洋文）
3.  组织徽标图案的链接
4.  组织主页的链接（可以是社媒主页）
5.  组织性质（学生社团/交流群/社团部门/同好会……）

### 注意事项

1.  本页面禁止一切与奶龙、奶娃、奶蛋等诸如此类相关内容
2.  不允许非校内的社会组织提交
3.  允许任何来自山西的高校学生组织提交，不允许非高校或非山西地区的组织提交
4.  请遵守相关法律法规
5.  请勿重复提交
